# Лабораторная работа 2. Классы и инкапсуляция

## Инварианты предметной модели ProjectTask

1. **Идентификатор задачи (`id`)**: не может быть `null`, пустым или состоять только из пробелов (`!id.isBlank()`). Значение нормализуется (обрезаются крайние пробелы) и является неизменяемым (`final`).
2. **Название задачи (`title`)**: не может быть `null`, пустым или состоять только из пробелов (`!title.isBlank()`). Значение нормализуется и является неизменяемым (`final`).
3. **Статус задачи (`status`)**: строго обязательное поле, не может быть `null`. Изменяется исключительно через специальный метод `changeStatus(TaskStatus)`, где также выполняется проверка на `null`.
4. **Трудоемкость (`estimatedHours`)**: строго положительное целое число (`> 0`). Увеличивается только методом `increaseEstimatedHours(int)`, принимающим строго положительную добавку (`> 0`).
5. **Инкапсуляция**: все поля закрыты (`private`), общие сеттеры отсутствуют.
