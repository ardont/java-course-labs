# Лабораторная работа 6. Коллекции и введение в дженерики

## Обоснование выбора коллекций для аналитики

1. **Группировка по статусам (`Map<TaskStatus, Integer>`)**:
   - Использован `HashMap` (или `EnumMap`), так как требуется ассоциативное хранилище вида «ключ — счетчик» с константным временем доступа $O(1)$ для поиска и обновления счетчика статуса.
2. **Уникальные категории (`Set<String>`)**:
   - Использован `LinkedHashSet`, поскольку требуется гарантировать уникальность строковых категорий без дубликатов, сохраняя порядок их первого обнаружения в исходном списке. Проверка наличия и добавление выполняются за $O(1)$.
3. **Сортировка задач (`List<ProjectTask>`)**:
   - Создается копия в `ArrayList` для сохранения неизменности исходного списка. Сортировка выполняется стандартным алгоритмом `Collections.sort` с помощью `Comparator.comparingInt(...).thenComparing(...)`, что предотвращает целочисленное переполнение, возникающее при простом вычитании чисел.
